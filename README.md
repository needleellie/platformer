# Платформер

Небольшая 2D-игра на Python и Pygame.

Игрок проходит уровни, собирает монетки, стреляет по врагам и переходит на следующий уровень через портал.

## Что используется

- Python
- Pygame
- Tiled для карт уровней
- JSON для координат врагов

## Запуск

Установите зависимости:

```bash
pip install pygame pytmx
```

После этого:

```bash
python main.py
```

## Структура

- `main.py` — игровой цикл, загрузка уровня и взаимодействие объектов;
- `player.py` — игрок и снаряд;
- `enemy.py` — общий класс для всех врагов;
- `world.py` — платформы, монетки и портал;
- `settings.py` — основные настройки игры;
- `maps/` — карты и данные о расположении врагов;
- `sprite/` — изображения и анимации.

У разных врагов могут быть разные спрайты и количество кадров анимации, но логика их движения находится в одном классе `Enemy`.
